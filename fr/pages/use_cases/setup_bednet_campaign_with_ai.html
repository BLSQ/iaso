    Configurer une campagne de distribution de MILDA avec l'IA#

    Configurez IASO pour une distribution de masse de moustiquaires imprégnées d'insecticide à longue durée d'action (MILDA) avec l'aide d'un assistant IA.

    Ce guide s'adresse aux coordinateurs de campagne et aux points focaux informatiques qui veulent utiliser IASO pour planifier et suivre une campagne MILDA. Pas besoin d'être développeur : un assistant IA (Claude, ChatGPT…) fait le travail technique, vous pose des questions sur votre campagne et attend votre accord avant de modifier quoi que ce soit dans IASO. Il rend la configuration de la campagne plus rapide, surtout si la plupart des décisions de la campagne sont déjà prises.

    Avant de commencer#

    Il vous faut Détails
    Un compte IASO Vous pouvez créer un essai gratuit sur openiaso.com/pricing.
    Un assistant IA Capable d'exécuter du code Python et d'accéder à votre serveur IASO : Claude ou ChatGPT dans le navigateur ou dans leur application, ou Claude Code (application de bureau ou terminal) avec Python 3 sur votre ordinateur.
    Vos fichiers et décisions de campagne Seulement si vous voulez tester avec les données réelles de votre campagne. Vos données géographiques (depuis DHIS2, un fichier Excel ou un fichier GeoPackage : l'assistant les importe pour vous, ou vous pouvez les importer vous-même) et les décisions de la campagne : districts couverts, règle d'attribution des moustiquaires, rôles et taux journaliers des travailleurs, liste des magasins, liste des agents (voir les questions de l'assistant à l'étape 5). Sinon, l'assistant peut proposer des données de démonstration pour tester d'abord la configuration.
    Un téléphone Android Avec l'application IASO sur Google Play, pour tester les projets mobiles.

    Vous utilisez un autre assistant IA ?

    Ce guide a été testé avec Claude et ChatGPT. Si vous rencontrez des difficultés avec un autre assistant IA, vos retours nous intéressent : contactez-nous à products@bluesquarehub.com.

    Votre adresse IASO

    Tout ce guide se déroule sur https://app.openiaso.com. Les comptes d'essai ont déjà tous les modules nécessaires à la campagne (formulaires, entités, gestion de stock, liens intégrés, mapping DHIS2).

    Vous utilisez Claude ? Préférez Claude Code

    Si vous utilisez Claude, utilisez de préférence Claude Code (application de bureau ou terminal) pour éviter les limitations. Claude dans le navigateur ou dans son application ne peut joindre que les domaines d'une liste autorisée : avec un serveur IASO autre que app.openiaso.com, faites autoriser son domaine avant la session (sur les offres Team et Enterprise, seul un propriétaire de votre organisation Claude peut l'ajouter : voir l'astuce à la fin de l'étape 4).

    Partie 1 : Préparer votre compte IASO#

    Étape 1 : Ouvrir votre compte IASO#

    1. Allez sur votre compte IASO sur app.openiaso.com, ou créez-en un sur openiaso.com/pricing.
    2. Choisissez l'utilisateur pour la configuration : l'assistant travaille dans IASO en tant que cet utilisateur. Vous pouvez utiliser l'utilisateur principal de votre compte nouvellement créé : il a déjà toutes les permissions dont le kit a besoin (listées dans SKILL.md, section 1). Idéalement, créez un utilisateur dédié à la configuration.

    Partie 2 : Configurer la campagne avec le kit de campagne#

    Le kit de campagne IASO est un fichier zip d'instructions, de formulaires, de modèles et de petits scripts écrits pour un assistant IA. Ce n'est pas un logiciel à installer : vous le donnez à l'assistant, qui le suit étape par étape pour construire votre campagne dans IASO. L'assistant travaille dans IASO avec les scripts du kit et la clé d'accès que vous lui donnez à l'étape 3.

    Étape 2 : Télécharger le kit#

    Téléchargez le kit dans la langue dans laquelle l'assistant doit travailler, et décompressez-le sur votre ordinateur :

    • Kit de campagne en français (zip, 6,1 Mo)
    • Kit de campagne en anglais (zip, 5,6 Mo)

    Les deux kits contiennent les mêmes formulaires, avec des libellés en français et en anglais.

    Étape 3 : Donner au kit l'accès à votre compte IASO#

    Le kit a besoin d'une clé d'accès (un « token ») pour travailler dans votre compte IASO en votre nom.

    1. Ouvrez ce lien et connectez-vous avec l'utilisateur pour la configuration : https://app.openiaso.com/login/?next=/api/apitoken/
    2. La page affiche une ligne comme {"token": "eyJ0eXAiOiJKV1Qi…"}. Copiez le long texte entre la deuxième paire de guillemets : c'est votre clé d'accès.
    3. Décompressez le fichier ZIP.
    4. Dans le dossier du kit, ouvrez le fichier iaso_config.txt avec un éditeur de texte (Bloc-notes, TextEdit…).
    5. Vérifiez que la ligne IASO_URL= indique https://app.openiaso.com. Collez votre clé d'accès après IASO_TOKEN=. Enregistrez le fichier.
    6. Recompressez le dossier du kit en zip.

    Gardez votre clé d'accès privée

    La clé d'accès fonctionne comme votre mot de passe. Ne la collez jamais dans la conversation et ne partagez jamais le zip une fois qu'il la contient. Gardez le kit avec sa clé en lieu sûr : il vous servira pour revenir vers l'assistant et faire des modifications plus tard (voir l'étape 7).

    Étape 4 : Donner le kit à votre assistant IA#

    1. Démarrez une nouvelle conversation dans Claude ou ChatGPT et joignez le zip contenant le token enregistré dans le fichier .txt.
    2. Choisissez l'origine de vos données géographiques et copiez tel quel le message correspondant.

    Option A : Utiliser les données géographiques de démonstration (pyramide de démonstration du kit et réponses d'exemple). La plupart des gens commencent ici : il n'y a rien à préparer, et vous voyez le résultat avant de préparer vos propres données. Copiez ce message, puis allez directement à l'étape 5 pour répondre aux questions :

    Voici un kit pour configurer une campagne de distribution de MILDA dans IASO. Décompresse-le si besoin, lis SKILL.md et suis-le étape par étape pour me guider. N'utilise que les scripts du kit, aucun connecteur IASO. C'est une démo : utilise la pyramide de démonstration du kit et propose des réponses fictives pour tout, dans un seul récapitulatif (mode démo). Demande-moi confirmation avant chaque étape qui écrit dans IASO, et ne t'arrête qu'après la liste du § 12c.

    Si l'assistant n'arrive pas à joindre IASO, voyez l'astuce à la fin de cette étape.

    Option B : Utiliser vos propres données géographiques. Reportez-vous au guide utilisateur pour plus de détails sur la façon de formater votre fichier GeoPackage ou Excel, ou de connecter votre instance DHIS2. Pour obtenir l'aide du kit avec vos données, utilisez l'un de ces messages :

    Vos données géographiques dans un fichier Excel (joint à la conversation) :

    Voici un kit pour configurer une campagne de distribution de MILDA dans IASO. Décompresse-le si besoin, lis SKILL.md et suis-le étape par étape pour me guider. N'utilise que les scripts du kit, aucun connecteur IASO. Mes unités d'organisation sont dans le fichier Excel joint. Pose-moi les questions de la campagne une section à la fois. Demande-moi confirmation avant chaque étape qui écrit dans IASO, et ne t'arrête qu'après la liste du § 12c.

    Avec un fichier GeoPackage, utilisez ce message en écrivant « GeoPackage » au lieu d'« Excel ».

    Vos données géographiques dans DHIS2 (déjà configuré sur la source de données dans IASO) :

    Voici un kit pour configurer une campagne de distribution de MILDA dans IASO. Décompresse-le si besoin, lis SKILL.md et suis-le étape par étape pour me guider. N'utilise que les scripts du kit, aucun connecteur IASO. Mes unités d'organisation viennent de notre DHIS2, déjà configuré sur la source de données IASO. Pose-moi les questions de la campagne une section à la fois. Demande-moi confirmation avant chaque étape qui écrit dans IASO, et ne t'arrête qu'après la liste du § 12c.

    L'assistant travaille dans son propre espace : demandez-lui de vous donner en téléchargement les fichiers qu'il produit (QR codes, mots de passe des utilisateurs, sauvegarde).

    L'assistant n'arrive pas à joindre IASO ?

    Les scripts du kit doivent accéder à app.openiaso.com par internet. Si l'assistant signale « Name or service not known » ou indique que son code ne peut pas se connecter, son code n'a pas le droit de joindre cette adresse :

    • Claude, abonnement personnel : dans Paramètres > Capacités, autorisez l'exécution de code à accéder au réseau et ajoutez exactement app.openiaso.com (openiaso.com seul ne suffit pas).
    • Claude, abonnement Team ou Enterprise : seul un propriétaire de votre organisation Claude peut le faire, dans Paramètres de l'organisation > Capacités. Vous pouvez lui envoyer ce message : « Bonjour, j'utilise Claude pour configurer une campagne dans IASO. Peux-tu ajouter exactement app.openiaso.com aux domaines que l'exécution de code de Claude peut joindre (Paramètres de l'organisation > Capacités) ? Sans cela, Claude ne peut pas joindre notre serveur IASO. Merci ! »
    • ChatGPT et les autres assistants : vérifiez dans leurs paramètres que l'exécution de code peut accéder à internet, ou à cette adresse.

    Demandez-lui ensuite de réessayer.

    Étape 5 : Répondre aux questions de l'assistant#

    L'assistant pose ses questions un thème à la fois (en démo, il propose toutes les réponses d'un coup, dans un seul récapitulatif à valider).

    Tout n'est pas encore décidé ? Vous pouvez quand même tester la configuration de la campagne : l'assistant peut proposer des données de démonstration (pyramide de démonstration, exemples de districts, de magasins et d'agents) que vous remplacerez ensuite par les vôtres.

    L'assistant construit ensuite la campagne étape par étape, en demandant votre accord à chaque fois : données géographiques, projets, formulaires, registres, stock, utilisateurs, tableaux de bord et rapports mobiles.

    Plus vous avez déjà pris de décisions, plus la configuration est rapide :

    Thème Questions À préparer
    Campagne nom, pays, langues des formulaires, districts couverts, nombre de moustiquaires par ménage la liste des districts, la règle d'attribution
    Géographie d'où viennent vos lieux, à quel niveau les ménages sont enregistrés (village, formation sanitaire…) vos paramètres DHIS2 dans IASO, ou votre fichier Excel ou GeoPackage
    Projets quels projets mobiles sont nécessaires (dénombrement, distribution, groupes spéciaux, travailleurs, stock, supervision) —
    Rapports quels tableaux de bord et rapports mobiles, la carte des ménages et ses noms de lieux, et qui peut ouvrir chaque page la liste des personnes qui suivent la campagne
    Travailleurs les rôles, les taux journaliers, qui valide la présence la grille de paiement
    Stock les magasins suivis, le nombre de moustiquaires par balle la liste des magasins
    Utilisateurs qui utilise quel projet, dans quelle zone la liste des agents

    L'assistant montre les QR codes à la fin, une fois chaque projet entièrement configuré (formulaires, registres et leurs suivis, stock, utilisateurs et rapports) : avant, l'application serait vide ou incomplète. Il vous donne aussi une feuille de QR codes de test (tickets de ménage, moustiquaires, ballots), puisque vous n'en avez pas encore de vrais : imprimez-la, ou scannez-la sur votre écran.

    Étape 6 : Tester sur un téléphone#

    1. Installez l'application IASO sur un téléphone Android depuis Google Play (ou scannez le QR code du Play Store que l'assistant vous donne).
    2. Choisissez l'utilisateur de test : un utilisateur de test créé par l'assistant, ou votre propre utilisateur (l'assistant propose de vous ajouter aux projets de la campagne). Dans les deux cas, cet utilisateur doit avoir les projets que vous voulez tester : dans IASO, allez dans Admin > Utilisateurs, modifiez l'utilisateur et, dans Projets, sélectionnez les projets à tester. Pour essayer les différents projets et passer de l'un à l'autre, sélectionnez-les tous.
    3. Trouvez les QR codes dans IASO : ouvrez le menu et allez dans Admin > Projets. Chaque projet mobile de la campagne y est listé, avec son QR code prêt à scanner.
    4. Ouvrez l'application IASO sur le téléphone, choisissez de scanner un QR code et scannez le QR code du projet à tester. Acceptez les demandes d'autorisation qui s'affichent (appareil photo, localisation…).
    5. Connectez-vous avec l'utilisateur choisi au point 2.
    6. Suivez le test guidé que l'assistant propose, avec les QR codes de test : enregistrer deux ménages avec les tickets de test, distribuer des moustiquaires à l'un d'eux, enregistrer un groupement spécial et un travailleur, saisir un mouvement de stock. Une nouvelle campagne n'a pas de données : c'est ce qui remplit les listes, les suivis et les rapports de chaque projet.
    7. Ouvrez les rapports mobiles, avec réseau puis en mode avion.

    Où sont les formulaires de stock ?

    Sur les serveurs qui ont l'écran d'accueil du stock, le projet Stock s'ouvre sur les magasins et leurs formulaires. Sinon, l'assistant ajoute un onglet Collecte de données au projet Stock : ouvrez-le, choisissez le magasin, et les formulaires de stock sont listés. Sans cet onglet, les formulaires de stock sont sous Entités > Mise à jour des stocks, puis le magasin, puis Editer à côté de son nom.

    Avant de former les équipes de terrain, demandez à l'assistant de supprimer les données et les utilisateurs de test.

    Étape 7 : Après la configuration#

    • Pour modifier quelque chose pendant la campagne (une question d'un formulaire, un nouveau district, un rapport), demandez-le simplement à l'assistant : revenez vers lui avec le kit, qui contient toujours votre clé d'accès. Les formulaires déjà utilisés sur les téléphones doivent être modifiés avec précaution : le kit explique à l'assistant comment faire.
    • Suivez la campagne dans les tableaux de bord web (menu Pages dans IASO) et dans les rapports mobiles. Le tableau de bord de la campagne et le rapport d'avancement montrent les ménages sur une carte (fond de carte du serveur de tuiles de Bluesquare, tiré d'OpenStreetMap) : dans le tableau de bord, cliquez sur une ligne du tableau pour zoomer sur ce lieu.
