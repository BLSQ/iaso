Limits on how many runs of a background task can happen at the same time, checked by the worker when a task is about to start. A task over a limit stays queued and is retried later. Changes apply to the next task starts. Only the SQS worker enforces them, see beanstalk_worker/throttle.py. See how they are used on the task monitor.

Every task has the limits global (all its runs), account (per account id) and user (per launching user id); its code can declare others. A limit with a key applies to each key value separately, and can be overridden for some keys.
